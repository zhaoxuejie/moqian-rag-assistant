# contracts · 前后端唯一约定

本目录放**机器可读契约**：前端按它写，后端按它实现。契约只描述**形状**，不描述检索与生成策略。

| 文件 | 是什么 | 怎么用 |
|---|---|---|
| [`openapi.yaml`](./openapi.yaml) | 接口契约：浮层问答链 + 后台治理链 + SSE 事件载荷 | 前后端共同维护；改接口先改这里 |
| [`seed/admin.json`](./seed/admin.json) | 后台页面的静态示例数据（早期原型的快照） | 只读参考，不参与运行时 |
| [`seed/widget.json`](./seed/widget.json) | 浮层页面的静态示例数据（同上） | 只读参考，不参与运行时 |

## 四条规则

1. **形状以本文件为准**：字段名、类型、错误码、SSE 事件名，前后端都以这里为唯一出处。
2. **改接口 = 改契约**：先改 `openapi.yaml`，再同步前后端适配层；不要只改一边。
3. **未定项不臆造**：拿不准的字段/行为标 `[待确认]` 并登记到 `info.x-pending-questions`。
4. **seed 是快照**：`seed/*.json` 只记录示例数据的形状，运行时数据一律来自真实接口，不要照着它写逻辑。
